A BTC trading bot for make.fun's "Race a BTC trading bot live for 24 hours" bounty: buys 100% of cash on the first tradable bar, holds with a 2.5% trailing stop, and re-enters only on a confirmed up-leg (60-bar momentum above +1.5% and close above EMA(60)). Deterministic, long-only, no leverage.

## Run it

```sh
node main.ts
```
